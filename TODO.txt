    - The next step in this analysis is to take the steady state profiles and show that they have variable sensitivity to a perturbation despite having the same ELA. This is obvious, but bears demonstrating within the parameter-sweep framework.
    - As part 1 of more targetted tests, a set of steady-state profiles should be found that have the same length and average thickness (variable ELA). These glaciers look identical but do not behave the same. This would demonstrate that glacier geometry alone cannot be used to constrain a glacier model.
    - In part 2 of more targetted tests, parameters should be found that have the same average thickness and b_t so as to have the same tau. Whether this is possible using the same bed shape among set members would be an important numerical test of the limits of linear theory. By allowing bedshape to vary, this likely will be possible. Demonstrating that the sensitivity varies in this case would also be a critical result.
        - In order to accomplish a variable bedshape, I expect that a fairly inefficient grid search will be required. To make this possible, the inputs should simply be a mass balance curve and a bed shape curve. Combinations of parameters in the simple (non PDD) mass balance model can be used to generate the shape of the balance curve. Some parameters will need to be fixed from the outset to accomodate the computational scale. These parameters should probably be: elevation change, and length. Hypsometry should be variable. Cluster analysis on RGI can be used to pick some representative parameters. A reasonable deomonstration would be to do this analysis 4 times to cover the range of short to long and steep to shallow (slope). Analysis of GlaThiDa can be done to determine reasonable parameter ranges for bedshapes. Because the sample size is small, a much larger range should be considered possible, and an estimate of the population variability can be calculated. This might be through a spectral analysis, with some specific research used to determine the range of roughness. This could be analysis of proglacial areas and downstream lines.
